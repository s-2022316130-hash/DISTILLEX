The principle

Three things happen on every tray

A column is one idea repeated. Boil a little, let the vapour meet the liquid coming down, condense a little — and each repetition moves the mixture further apart.

01 · Boil
Heat makes vapour

The reboiler boils liquid at the sump. Because the lighter component is more volatile, the vapour leaving is already richer in it than the liquid it came from.

02 · Enrich
Each tray is one stage

Vapour rises, liquid falls, and they exchange on every tray. One tray is one equilibrium stage — and stacking them is what turns a small difference in volatility into a clean split.

03 · Return
Reflux does the work

Condense the overhead and send part of it back down. That returned liquid is what every rising vapour meets — more reflux, fewer stages needed, more energy spent. The trade-off you set in the simulator.

From theory to industry

From crude oil to products

The same stagewise separation you build in the simulator, at refinery scale. One tower, one feed, eight cuts — each condensing where the temperature matches its boiling range.

DISTILLEX

An interactive fractional-distillation laboratory for binary mixtures. Every value on screen is computed in the browser from the selected thermodynamic model: there is no server, no stored data and no pre-baked result. The calculation layer — Antoine vapour pressure, bubble and dew points, equilibrium interpolation, q-line, minimum reflux, operating lines, stage stepping, material balance, recovery and duties — is written as named functions so it can be tested and extended to other unit operations.

Engineering models

Ideal VLE (Raoult's law) with Antoine vapour pressures in mmHg and °C, and a constant-relative-volatility model. Stage calculations follow McCabe–Thiele under constant molar overflow; minimum reflux includes a tangent-pinch check; minimum stages use Fenske with a geometric-mean α. Activity-coefficient models (Wilson, NRTL, UNIQUAC) are not implemented — mixtures that need them are flagged rather than silently approximated.

Data provenance & validation

Antoine constants are the Reid–Prausnitz–Poling / Lange sets in mmHg and °C, each stored with the temperature range it was fitted over; the VLE Explorer prints that range and re-derives each pure-component vapour pressure at its own normal boiling point as a self-check (benzene 759.0 mmHg at 80.0 °C, water 757.6 mmHg at 100.0 °C — both ≈ 760). Latent heats are values at the normal boiling point. Stage temperatures outside a fitted range raise an extrapolation warning rather than silently degrading. Known azeotropes are recorded per mixture — ethanol/water at 95.6 wt% ethanol (x ≈ 0.894), boiling at 78.2 °C at 1 atm — and any specification that crosses one is flagged as physically unreachable, whatever the ideal model computes.

Limitations

Binary systems only. No column hydraulics (flooding, weeping, pressure drop, diameter). Duties are latent-heat only. Tray efficiency is applied as a single overall value. Packed columns are not modelled: no HETP, packed height or transfer-unit (HTU/NTU) calculation is performed. Azeotropic systems cannot be represented by either model offered.

Deployment
  1. Create a GitHub repository and push this project.
  2. Import the repository into Vercel — it is a static client-side app, so no build configuration or environment variables are required.
  3. Deploy, then open the generated Vercel URL.
  4. To update the live site, push to the tracked branch: Vercel rebuilds and redeploys automatically.
Extending it

The thermodynamic layer (vapour pressure, equilibrium, temperatures), the unit-operation engine (balances, stage stepping, duties), the visualisation layer and the mixture data are separate concerns. A new unit operation — absorption, extraction, evaporation, a heat exchanger — needs a new engine module and view; the thermodynamic and data layers are reused unchanged.
